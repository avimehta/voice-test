# Voice test

Blind listening test of text-to-speech voices for calm, curious narration. Each clip reads the same short passage about penicillin.

Open the page, listen, rate each clip 1–5, flag mispronunciations, add notes, then press **Reveal** to see which provider, model and voice each clip was. Press **Submit results** to send your ratings and notes (add your name if you like). You can change your answers and submit again; it replaces your earlier submission.

Contents: `index.html` (the page) and `audio/` (the MP3 clips). No code or credentials.
